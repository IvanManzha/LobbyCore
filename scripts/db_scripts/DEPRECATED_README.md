# ⚠️ DEPRECATED SCRIPTS

Эти скрипты помечены как устаревшие, так как теперь используется автоматический мониторинг матчей через `MatchMonitorService`.

## Устаревшие скрипты:

### `fetch_And_Save_Match.js`
**Статус:** DEPRECATED  
**Причина:** Заменен автоматическим мониторингом  
**Альтернатива:** Мониторинг автоматически загружает матчи при запуске турнира

### `fetch_and_save_many_matches.js`
**Статус:** DEPRECATED  
**Причина:** Заменен автоматическим мониторингом  
**Альтернатива:** Мониторинг автоматически загружает все новые матчи

### `refetchEntireMatch.js`
**Статус:** DEPRECATED (но может быть полезен для исправления данных)  
**Причина:** Заменен автоматическим мониторингом  
**Альтернатива:** Используйте API endpoint для перезагрузки матча (если будет добавлен)

## Как теперь работает:

1. Админ нажимает "Начать турнир" в UI
2. Автоматически запускается `MatchMonitorService`
3. Мониторинг каждые 2 минуты проверяет новые матчи участников
4. Автоматически сохраняет матчи в БД и обновляет таблицу

## Если нужно вручную загрузить матч:

Используйте API endpoint (если будет добавлен) или временно запустите `refetchEntireMatch.js` для исправления данных.
