# Stats Engine

Единый модуль для расчёта статистики игроков и турниров. Обеспечивает прозрачные определения метрик, корректную обработку отсутствующих данных и coverage для неполных данных.

## Core Metrics (Уровень 1)

### Rating
- **Определение**: Итоговый рейтинг игрока на основе эффективного рейтинга (effective rating)
- **Формула**: `effectiveRating ?? rating ?? null`
- **Формат**: Целое число
- **Tooltip**: Показывает breakdown: WindowRating, Long anchor, Short anchor
- **При отсутствии данных**: `"—"`

### Matches played
- **Определение**: Количество завершённых матчей (с известным местом)
- **Формат**: Целое число
- **Tooltip**: "Общее количество завершённых матчей (с известным местом)"
- **При отсутствии данных**: `0` (не `"—"`, так как это счётчик)

### Avg place
- **Определение**: Среднее место по всем завершённым матчам
- **Формула**: `sum(places) / completedMatches.length`
- **Формат**: 1 знак после запятой (например, `2.5`)
- **Tooltip**: "Среднее место по всем завершённым матчам (чем меньше, тем лучше)"
- **При отсутствии данных**: `"—"`

### Kills / Match
- **Определение**: Среднее количество киллов за матч
- **Формула**: Считается только по матчам, где киллы были учтены (coverage)
- **Формат**: 1 знак после запятой (например, `3.2`)
- **Tooltip**: "Среднее количество киллов за матч (считается только по матчам, где киллы были учтены)"
- **Coverage badge**: Показывается "!" если `trackedMatches < totalMatches`
- **При отсутствии данных**: `"—"`

### Winrate
- **Определение**: Процент побед (1 место) от общего числа завершённых матчей
- **Формула**: `(wins / completedMatches.length) * 100`
- **Формат**: Целые проценты (например, `25%`)
- **Tooltip**: "Процент побед (1 место) от общего числа завершённых матчей"
- **При отсутствии данных**: `"—"`

### Top-X%
- **Определение**: Процент матчей, где игрок попал в Top-N
- **Адаптация**: 
  - Для больших лобби (≥10 участников): Top-3
  - Для малых лобби (<10 участников): Top-50% (верхняя половина)
- **Формат**: Целые проценты (например, `67%`)
- **Tooltip**: "Процент матчей, где игрок попал в {Top-X%} (адаптируется для малых лобби)"
- **При отсутствии данных**: `"—"`

### K/D
- **Определение**: Отношение киллов к смертям
- **Формула**: `totalKills / totalDeaths` (только по матчам с deaths)
- **Формат**: 2 знака после запятой (например, `1.50`)
- **Tooltip**: "Отношение киллов к смертям (считается только по матчам, где смерти были учтены)"
- **Coverage badge**: Показывается "!" если deaths tracked < total matches
- **При отсутствии данных**: `"—"` (если deaths не трекались)

### Form last 5
- **Определение**: Последние 5 матчей, визуализированные точками
- **Визуализация**: 
  - Зелёная точка = попадание в Top-3
  - Красная точка = не попадание в Top-3
- **Tooltip**: "Последние 5 матчей, подсвечены попадания в Top-3"

## Secondary Metrics (Уровень 2)

### Best place
- **Определение**: Лучшее место за период
- **Формат**: Целое число
- **При отсутствии данных**: `"—"`

### Best kills (match)
- **Определение**: Максимум киллов в одном матче
- **Формат**: Целое число
- **При отсутствии данных**: `"—"`

### Avg points / Match
- **Определение**: Средние очки за матч
- **Формат**: 1 знак после запятой
- **При отсутствии данных**: `"—"`

### Placement distribution
- **Определение**: Распределение мест по категориям (1-3, Top-X, остальные)
- **Формат**: Строка (например, `"1-3: 2, Top-10: 1, Остальные: 3"`)
- **При отсутствии данных**: `"—"`

### Stability
- **Определение**: Доля матчей в верхних 30% таблицы
- **Формула**: `(matchesInTop30% / totalMatches) * 100`
- **Формат**: Целые проценты
- **Tooltip**: "Стабильность = доля матчей в верхних 30% таблицы"
- **При отсутствии данных**: `"—"`

### Top-3 streak
- **Определение**: Лучшая серия попаданий в Top-3 подряд
- **Формат**: Целое число
- **При отсутствии данных**: `"—"`

## Coverage

Coverage показывает, в скольких матчах реально есть данные по киллам/смертям.

### Примеры
- `Kills tracked: 4/6` — киллы известны в 4 из 6 матчей
- `Deaths tracked: 2/6` — смерти известны в 2 из 6 матчей

### Правила
- Метрики считаются **только по матчам с данными**
- Если coverage неполный, показывается badge "!" с предупреждением
- Coverage badge имеет цветовую индикацию (жёлтый/оранжевый)

### Coverage для K/D
- K/D считается только если есть deaths хотя бы в одном матче
- Если deaths не трекались вообще, K/D = `"—"`

## Live/Done Tournaments

### Правила фильтрации
- **All-time метрики**: Используют только турниры со статусом `DONE`
- **Live турниры**: Доступны отдельно через `scope: 'live_only'` и не смешиваются с all-time
- **Year метрики**: Используют только завершённые турниры за выбранный год

### Статусы турниров
- `REG` — Регистрация (не учитывается в статистике)
- `LIVE` — В процессе (не учитывается в all-time)
- `DONE` — Завершён (учитывается в all-time)

## Rating Breakdown

Рейтинг рассчитывается на основе эффективного рейтинга (effective rating), который учитывает:
- **Window Rating**: Средний рейтинг за последние N турниров (по умолчанию 5)
- **Long Anchor**: Долгосрочная опора (базовый рейтинг)
- **Short Anchor**: Краткосрочная опора (средний за последние M турниров, по умолчанию 10)

### Формула
```
Рейтинг = WindowRating + влияние долгосрочного и краткосрочного якоря
```

### Tooltip
Показывает breakdown в формате:
```
Рейтинг = Window(5): 1250.5 · Long anchor: 1200.0 · Short anchor: 1230.0
```

## Форматирование

### Общие правила
- Все метрики показывают `"—"` вместо `0` при отсутствии данных
- Числовые значения используют `tabular-nums` для выравнивания
- Проценты округляются до целых
- Средние значения округляются до 1 знака после запятой
- K/D округляется до 2 знаков после запятой

### Обработка null/undefined
- Все деления через `safeDivide` (возвращает `null` при делении на 0 или null)
- Все проценты через `clamp(0, 100)` для предотвращения выхода за границы
- Все форматирование проверяет `null` и возвращает `"—"`

## Адаптация для форматов

### Top-N метрики
- **Solo/Duo/Squad/Mixed**: Top-3 для больших лобби, Top-50% для малых
- **Малые лобби**: <10 участников → Top-50% вместо Top-10
- **Winrate**: Всегда победа = 1 место (независимо от формата)

### Участники
- `participantsCount` учитывается для адаптации порогов Top-N
- Если `participantsCount` неизвестен, используются дефолтные значения (Top-3, Top-10)
