# Миграция: переход на percentile-based Ladder Rating

Документ фиксирует замену старой системы рейтинга (фиксированные очки за места) на единственную актуальную — **percentile-based Ladder Rating**. Дизайн новой системы: [Ladder-Rating-System.md](Ladder-Rating-System.md).

---

## 1. Что считалось старой системой

- Фиксированные очки за места (+10 за 1-е, +8 за 2-е и т.д.).
- Ручные начисления по таблице мест.
- Очки «просто за участие».
- Любые расчёты глобального рейтинга из `ratingRules.placement` и `ratingRules.default`.
- Тексты в UI, описывающие «рейтинг за 1–3 место и остальные».

---

## 2. Новая единственная система

**Ladder Rating** — обновляется один раз после завершения турнира по формулам:

- `ActualScore = (1 - (place - 1) / (N - 1))^gamma`
- `ExpectedScore = 1 - (expectedRank - 1) / (N - 1)`
- `DeltaLadder = K_tour * (ActualScore - ExpectedScore) + Bonus`
- `Ladder_new = clamp(Ladder_old + DeltaLadder, LadderMin, LadderMax)`

Реализация: `src/backend/services/LadderService.js`. Вызов после закрытия турнира: `TournamentService.closeTournament` → `LadderService.updateAfterTournament`.

## 3. Что сделано в проекте

### 3.1. Backend

| Место                                                | Было                                                                               | Стало                                                                                                                       |
| ---------------------------------------------------- | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **StatsService.recalculateAllRatings()**             | Суммировал `ratingRules.placement[place]` по турнирам и записывал `profile.rating` | Метод оставлен для совместимости API; **не записывает** rating. Ladder обновляется в LadderService при закрытии турнира.    |
| **LadderService**                                    | Уже реализован percentile-based расчёт                                             | Без изменений; является единственным источником обновления Ladder.                                                          |
| **TournamentService.recalculateLeaderboard**         | Считает totalPoints по scoring.placement/per_kill, присваивает rank                | Без изменений: это **ранжирование внутри турнира**, не глобальный рейтинг. Результат (place, N) используется LadderService. |
| **ratingRules** в турнире (placement 1/2/3, default) | Использовались в recalculateAllRatings для «глобального рейтинга»                  | Больше **не используются** для расчёта рейтинга. Поля можно оставить в БД/админке для совместимости или удалить позже.      |

### 3.2. Frontend / i18n

| Место                                  | Было                                                           | Стало                                                                                                                             |
| -------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| **createTournament.scoringModalTitle** | «Система баллов и рейтинга»                                    | «Баллы турнира и Ladder» (RU) / «Tournament points and Ladder» (EN)                                                               |
| **scoringModalText1**                  | Очки за место по таблице + рейтинг не объяснялся отдельно      | Очки задают таблицу турнира и место в нём; они не глобальный рейтинг.                                                             |
| **scoringModalText2**                  | «Рейтинг считается по правилам: за 1–3 место начисляются очки» | «Ladder обновляется после турнира по относительному результату (место, размер поля, ожидания). Фиксированных очков за 1/2/3 нет.» |

### 3.3. Турнирные очки (scoring.placement, per_kill)

- **Не удаляются.** Они нужны для:
  - определения **места в турнире** (rank) и отображения таблицы;
  - ввода данных в матчах (placement, kills).
- Они **не** используются для глобального Ladder: Ladder считается по place и N в LadderService.

## 4. Поля и сущности

| Сущность                                         | Статус                                                                                                                   |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| **ladder_rating, ladder_rank_label, last_delta** | Актуальные; хранятся в `player_ladder` / отдаются в профиле.                                                             |
| **dna_rating**                                   | Отдельная система (skill); не трогалась.                                                                                 |
| **profile.rating** в JSON профиля                | В ответах API подставляется из DNA (enrichWithDnaRating). Запись старой «суммы очков» отключена в recalculateAllRatings. |
| **ratingRules** турнира                          | Legacy; не участвуют в расчёте рейтинга. Можно оставить в схеме для истории или удалить позже.                           |
| **totalPoints, rank** в таблице турнира          | Актуальны для турнира; используются для места (place) и в LadderService.                                                 |

## 5. Что проверить после замены

- [ ] Старая формула (сумма очков за места) нигде не вызывается для глобального рейтинга.
- [ ] Лидерборды (страница Ladder, профиль) используют только Ladder (и при необходимости DNA для отображения).
- [ ] Tournament result flow: после закрытия турнира вызывается LadderService.updateAfterTournament.
- [ ] В UI нет текстов про «рейтинговые очки за 1–3 место».
- [ ] Нет смешения: глобальный рейтинг = Ladder (и отдельно DNA для аналитики).

---

## 6. Итог

- **Единственная активная система рейтинга** в продукте — **Ladder Rating** (percentile-based), реализованная в LadderService.
- Старая логика начисления рейтинга по фиксированным очкам за места отключена (recalculateAllRatings не пишет rating).
- Тексты в модалке создания/редактирования турнира приведены в соответствие с новой системой.
- Турнирные очки (placement + per_kill) остаются только для ранжирования внутри турнира и таблицы.
